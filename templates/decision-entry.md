# 决策条目模板（Decision Entry）

> 使用说明：字段借鉴 MADR 精简版。每个编号在决策公告板发一条评论；入库时同样格式追加到决策记录。

```markdown
**D-YYYYMMDD-NN · <事项标题>**

- 状态：<已定·待入库 / 已入库 #PR / 被 D-xxx 取代>
- 事项：<一句话说明决定的问题>
- 决定：<内容>（<负责人原话 / 主管转述>）
- 决定者：负责人
- 问题：<提问评论链接（scripts/ask-post.sh 返回）>
- 负责人原话：<一字不改>（<时间与时区>）
- 取代：<D-yyy（全部 / 部分：范围）/ 无>
- 知会：<受影响的 PR 号与 Agent 角色名>
- 验证：<测试名、规格章节或审查项>
- 依据：<调研报告路径、规格条目、建议人与理由>
```

发布后，主管在「知会」列出的每个 PR 下发一行：`D-YYYYMMDD-NN 已定：<一句话>`。
