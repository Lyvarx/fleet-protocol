# 合并门记录模板（Merge Gate Record）

> 使用说明：由主管填写，记入状态流水或合并记录文件，不得写在被审分支上。

```markdown
# 合并门 · #<PR 号> · head <sha>

- 标题：<PR 标题>　作者：<执行 Agent 角色名>　任务号：<…>
- 类别：<普通 / 二审范围：…>
- 授权方式：<规则预授权 / 负责人逐单授权（部署、密钥、CI 配置）>

| # | 项目 | 结果 | 依据 |
|---|---|---|---|
| 1 | 覆盖 | 通过 / 不通过 | 一审 <编号>：<n>/<n> 文件逐行 |
| 2 | 执行检查 | 通过 / 不通过 | 各类文件对应检查与 run id；跳过项及兑现点 |
| 3 | 自报缺口 | 通过 / 不通过 | 逐条关闭或豁免编号 |
| 4 | 二审 | 通过 / 不适用 | 二审 <编号>，无未清阻断 |
| 5 | 新鲜度 | 通过 / 不通过 | CI 汇总检查通过于 head <sha>；是否需先同步 main：<是 / 否> |
| 6 | 体量 | 通过 / 不通过 | <n> 文件 / <n> 行 |
| 7 | 落脚点 | 通过 / 不通过 | <位置> |
| 8 | 界面用语 | 通过 / 不适用 | <…> |

- 在制品（合并前）：<n>/<上限>
- 分歧：<无 / 内容与处理>
- 处置：<已 squash 合并，合并提交 <sha> / 请负责人授权 / 退回>
- 合入后验证：main CI run <id> <结果>；大文件对象核验（适用时）<结果>
```
