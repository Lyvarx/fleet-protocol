# 转达文本模板（Relay Message）

> 使用说明：执行 Agent 与审查 Agent 不主动读取消息，也不会自行开工。主管发出任务书、修正单、评论答复或决策通知时，必须同时给负责人一段可直接转发的文本，不得写「无需转达」。同一轮多份内容一次给出，并先列「给谁｜哪份」。

主管给负责人的消息中：

```markdown
本轮需转发 <n> 份：
| 给谁 | 哪份 |
|---|---|
| <角色名> | <任务号 任务书 / 修正单 / 评论答复 / 决策通知> |
```

每份转达文本（负责人原样转发）：

```markdown
请先加载项目开工 skill「<开工 skill 名称>」。

<任务号> <任务书 / 修正单 / 评论答复 / 决策通知>：<链接（任务书留档评论、PR 评论或公告板条目）>
回报位置：<唯一位置>，标题「<任务号> 回报 · head <sha>」。

开工规程：
1. 列出自己开着的 PR，读上次回报之后的新评论与决策公告板新增条目；
2. 先按评论与修正单执行，再做手头的任务书；
3. 冲突时以较新的主管指令为准；无法判断时停手上报。
```

对不访问仓库的 Agent（操作协助、资料搬运），链接替换为任务书全文。
